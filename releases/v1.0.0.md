# HanTalk AI v1.0.0 — First public release

**Release date:** 2026-11-10
**Version:** `1.0.0` (versionCode 1)
**APK:** `HanTalkAI-1.0.0-release.apk`
**Minimum Android:** 8.0 (API 26)

---

## What it is

A Korean learning app for Android with a **built-in, fully local AI tutor**.
No account, no server, no network required once installed.

## Included

- **AI tutor** — rule-based offline tutor out of the box (alphabet, 받침, numbers,
  particles, politeness, romanisation, jamo breakdown), with optional on-device
  Gemma / Qwen models for free-form conversation.
- **Lessons** — six themed sets, 37 phrases, each with a syllable-by-syllable
  jamo breakdown, romanisation and one-tap *Practice* / *Explain*.
- **한글 alphabet** — all 19 consonants and 15 vowels with names, sounds, example
  words and a live demo syllable; progress is saved.
- **Practice** — translation drills scored by edit distance, Korean text-to-speech
  playback, a day streak and a best-score record.
- **AI models screen** — on-demand model downloads with resumable transfers.

## Notes

- APK ≈ 43 MB download / ≈ 105 MB installed (MediaPipe's native inference engine).
- Models are **not** bundled and are never uploaded; inference runs on the phone.
- CI signs with a throwaway key per build, so builds from different runs are not
  upgrade-compatible with each other.
- This is the last release before the voice-first redesign in v1.1.0.
